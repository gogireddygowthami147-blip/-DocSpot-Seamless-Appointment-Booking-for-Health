---

## ⚡ Quick Start

### 1. Backend (`/backend`)
```bash
cd backend
npm install
npm test      # Run automated integration test
npm run dev   # Starts backend server on port 5000
```

### 2. Frontend (`/frontend`)
```bash
cd frontend
npm install
npm run dev   # Starts Vite development server on port 5173
```

Refer to the root [README.md](../README.md) for full architecture, diagrams, REST API documentation, and test credentials.
